# LacI_DCI_DFI_IPTG_ONPF

Respository of data files and analysis scripts for a project comparing 
      (i) the computed flexibilitiy and dynamic coupling for LacI in three liganded states (Apo, IPTG-bound, and ONPF-bound)
      to (ii) experimental studies that identify amino acid positions in LacI with ligand-specific mutation outcomes

This work is a collaboration of the Ozkan lab (Arizona State University), the Ross lab (National Institute of Standards and Technology), and the Swint-Kruse lab (The University of Kansas Medical Center)
